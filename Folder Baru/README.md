# 💼 Website Curriculum Vitae (CV) Modern - Muhammad Rayhan Fadila

Website Curriculum Vitae (CV) dan Portfolio interaktif Muhammad Rayhan Fadila yang dirancang dengan konsep modern, rapi, terstruktur, elegan, dan estetik (*luxury executive style*).

---

## ✨ Fitur Unggulan Website

1. **Desain Modern & Estetik (Luxury Dark & Light Mode)**
   - Tersedia tombol pergantian tema (*Theme Switcher*) di kanan atas navbar antara **Dark Mode** (dominan warna obsidian gelap dengan aksen emas hangat & ambient glow) dan **Light Mode** (bersih, minimalis, dan elegan).
   - Pengaturan tema tersimpan otomatis pada *Local Storage* peramban pengguna.

2. **Tipografi Elegan & Terstruktur**
   - Font heading menggunakan **Syne** untuk kesan mewah dan berkarakter.
   - Font body menggunakan **Plus Jakarta Sans** untuk tingkat keterbacaan (*readability*) tinggi dan rapi.

3. **Foto Profil Asli & Dioptimasi**
   - Menggunakan foto asli dari dokumen CV yang telah diekstrak dan dipotong secara proporsional dan profesional ke format HD (`images/rayhan_photo.jpg`).

4. **Struktur Lengkap Sesuai Dokumen CV**:
   - **Beranda (Hero Section)**: Gelar keahlian, status ketersediaan kerja (*Open to Work* dengan animasi pulse hijau), ringkasan singkat, dan metrik pencapaian.
   - **Profil & 4 Pilar Utama**: Pernyataan visi dan nilai kerja (Disiplin & Tepat Waktu, Teliti & Terstruktur, Komunikasi & Tim, Cepat Beradaptasi).
   - **Data Pribadi (Biodata Lengkap)**: Kartu informasi interaktif dengan tombol **Salin / Copy ke Clipboard** untuk nomor WhatsApp/telepon dan alamat domisili lengkap disertai *toast notification*.
   - **Riwayat Pendidikan**: SMK Wiyata Satya (2021–2024), Jurusan Administrasi Perkantoran, dilengkapi rincian kompetensi kejuruan yang dikuasai.
   - **Keahlian & Kompetensi (Skills)**: Dibagi menjadi Keahlian Inti CV (Manajemen Waktu, Kerja Sama Tim, Komunikatif, Cepat Beradaptasi) dan Keahlian Teknis Administrasi Perkantoran dengan animasi *progress bar* saat di-*scroll*.
   - **Hubungi Saya & WhatsApp Generator**: Fitur pembuat pesan otomatis WhatsApp dengan pilihan topik (Undangan Interview, Tanya Ketersediaan Kerja, Diskusi Kualifikasi) langsung terhubung ke nomor `087775172933`.

5. **Dukungan Cetak / Simpan PDF (Print Ready)**
   - Dilengkapi file `css/print.css` khusus. Ketika menekan tombol **"Cetak / Simpan PDF"** atau `Ctrl + P`, tampilan website otomatis disesuaikan menjadi format cetak dokumen A4 resmi hitam-putih yang bersih tanpa tombol web.

6. **Responsif Sepenuhnya (Mobile & Desktop Friendly)**
   - Desain fleksibel untuk layar ponsel cerdas (Android/iPhone), tablet, laptop, dan monitor desktop dengan *mobile navigation drawer*.

## 📁 Struktur Direktori File

```

├── index.html          # File halaman utama HTML5 (Semantik & SEO friendly)

│   └── print.css       # CSS khusus format cetak A4 & ekspor PDF
├── js/
│   └── main.js         # Logika interaktif JavaScript (Mode tema, WA generator, copy toast, dll)

    ├── rayhan_photo.jpg      # Foto portrait resmi Muhammad Rayhan Fadila

```

## 🚀 Cara Menjalankan Website

1. Cukup klik ganda (*double click*) file `index.html` pada File Explorer Anda untuk membukanya di browser apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
2. Anda juga dapat menggunakan live server lokal (misalnya ekstensi *Live Server* di VS Code) jika diperlukan.
